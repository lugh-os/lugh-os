# Lugh GRUB theme (light). Every path is relative to this directory, so the
# directory can be copied as-is: /usr/share/grub/themes/lugh/ on installed
# systems, the GRUB theme directory on the live ISO.
#
# Fonts (the *.pf2 files here must be loaded with loadfont; grub-mkconfig's
# 00_header does this for every *.pf2 next to GRUB_THEME):
#   "Inter Regular 16", "Inter Regular 24", "Inter SemiBold Regular 24"
# The edit/command-line terminal uses GRUB's "GNU Unifont Regular 16"
# (unicode.pf2), which a proportional font cannot replace.
#
# Colors follow DESIGN-SYSTEM.md (light): bg #F7F6F3, text #1C1B19,
# text-muted #5F5B54, surface-3 #E4E1DA, accent #E8962E.
# Regenerate the PNGs and fonts with make-assets.sh.
